# PyAutoMacro - 极简键鼠自动化工具

## 项目简介
这是一个用 Python 编写的轻量级宏录制、回放工具，适合用于日常重复性的键鼠操作（如填表、测试、抢课练习）。
目前只适用英文
## 功能特性
- 【F9】一键录制：记录你的鼠标点击和键盘输入。
- 【F10】保存录制：将动作保存为本地 JSON 文件，下次可用。
- 【F11】无限循环：自动循环回放你的录制动作。
- 【Esc】紧急停止：随时打断，安全退出。
运行过程不要切换屏幕
## 环境依赖
运行前请确保安装了以下 Python 库：终端命令行下载
```bash
pip install pynput pyautogui
兼容性说明：本工具仅支持 Windows 及带图形界面的桌面系统，不支持 Android/iOS 等移动端，亦不适用于无图形界面的纯命令行服务器。
启动程序
按 Win + R，输入 cmd 弹出黑色窗口。（或者直接进入文件夹目录，上面直接cmd进入终端）
在窗口里输入 cd Desktop\MacroTest（意思是进入你桌面的那个文件夹），按回车。
输入 python macro.py 然后按回车。
出现页面即开始运行
